# Scholars' Paradise International School - IT & Operations Framework

This repository contains the dynamic data models, business intelligence dashboards, and digital campaign strategies designed to optimize campus operations and scale student admissions for SPIS Lucknow.

## 🚀 Key Modules Included
1. **Admission Inquiry Funnel & Analytics:** Multi-campus lead tracking (Vikas Nagar, Kursi Road, Kalyanpur) using structured preference analysis to optimize social media ROI.
2. **Campus IT Asset & Lab Uptime Log:** Automated inventory management system to guarantee 100% compute infrastructure uptime across all digital labs.
3. **Digital Brand & Social Media Media Plan:** Highly targeted visual campaign structures (Canva-optimized frameworks) integrating moral values (Tarbiyah) with tech-driven academic showcases.

## 🛠️ Technical Stack Utilized
- **Data Engineering & Reporting:** Advanced Excel, SQL Databases
- **Business Intelligence Tools:** Power BI, Tableau
- **Design & Layout Optimization:** Canva Studio Modules
